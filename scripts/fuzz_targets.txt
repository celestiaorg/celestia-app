# Registry of fuzz targets run nightly by scripts/test_fuzz.sh.
#
# WARNING: These fuzzers are a defense line against wire-format / codec bugs.
# The fibre scatter codec (fibre/internal/grpc/codec_scatter.go) is a hand-rolled
# marshaler that MUST stay byte-for-byte identical to gogoproto's canonical
# output, and the fibre shard codec is the on-the-wire shard encoding. DO NOT
# remove any target below without an equivalent replacement; silently dropping
# one re-opens https://github.com/celestiaorg/celestia-app/issues/7392.
#
# Columns: priority package target fuzztime minimizetime
#
# priority follows docs/fuzzing.md and sets the Linear priority of the issue the
# nightly job files when the target fails: 1 = Urgent, 2 = High, 3 = Medium.
# minimizetime is passed to -fuzzminimizetime; "-" keeps Go's default. Cheap
# targets use 100x so the workers keep fuzzing instead of minimizing.
#
# Every func Fuzz* in this repository must appear here exactly once;
# `scripts/test_fuzz.sh --check` enforces this.
