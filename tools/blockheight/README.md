# blockheight

blockheight is a small tool to help predict the block height of a chain at a given time.

## Usage

```shell
$ go run main.go https://rpc-mocha.pops.one:443 2026-10-01T14:00:00
chainID: mocha-5
currentHeight: 1134828
currentTime: 2026-09-26 13:56:29.400900095 +0000 UTC
targetHeight: 1171611
targetTime: 2026-10-01 14:00:00 +0000 UTC
diffInSeconds: 432210
diffInBlockHeight: 36783
```
